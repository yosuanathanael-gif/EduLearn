EDULEARN - VERSI LENGKAP UNTUK VS CODE

ISI:
- 3 mata kuliah: Pengantar Teknologi Informasi, Manajemen Proyek TI, Pemrograman Web.
- 9 materi pembelajaran dengan penjelasan dan ringkasan.
- 3 kuis, masing-masing 10 soal pilihan ganda.
- Nilai dihitung otomatis dan riwayat tersimpan di browser.
- Login demo dengan pilihan Admin, Dosen, dan Mahasiswa.

CARA MEMASANG:
1. Tutup tab browser EduLearn jika sedang terbuka (opsional).
2. Ekstrak ZIP ini.
3. Di VS Code pilih File > Open Folder.
4. Buka folder EduLearn_VSCode_Lengkap.
5. Pastikan index.html, style.css, dan app.js berada dalam satu folder.
6. Klik Go Live untuk menjalankan aplikasi.

CATATAN DATA:
Versi ini menggunakan localStorage dengan kunci edulearn_demo_v2 agar data contoh versi sebelumnya tidak menimpa materi dan kuis baru.
Jika browser masih menampilkan versi lama, refresh halaman dengan Ctrl + F5.

CATATAN PROYEK:
Ini masih prototipe front-end. Login demo belum menggunakan password dan belum aman untuk penggunaan nyata. Data hanya tersimpan pada browser/perangkat yang sama. Untuk penggunaan nyata diperlukan backend, autentikasi aman, database server, serta deployment.
